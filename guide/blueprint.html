Blueprint et indispensables ​

Un blueprint est la liste du contenu d'une instance (mods, shaders, packs de ressources) sous forme de texte. Collez-le dans une autre instance : Kodus y installe la version de chaque contenu compatible avec sa version de Minecraft et son loader. Idéal pour retrouver vos mods d'optimisation, vos shaders et vos packs dans une instance créée pour jouer à un mod précis.

Blueprint ou .kpack ? ​

Les deux servent à partager du contenu, mais pas dans le même but :

Modpack .kpackBlueprint
Ce que c'estUne copie exacte d'une instanceUne liste de contenus, adaptée à chaque instance
Version de MinecraftLa même (le .kpack crée l'instance)N'importe laquelle : Kodus cherche la bonne version de chaque contenu
LoaderLe mêmeN'importe lequel (Fabric, NeoForge…), sauf les contenus qui n'existent pas pour ce loader
Versions des modsIdentiques, au fichier prèsLes plus récentes compatibles avec l'instance cible
Réglages des modsInclus dans le fichierRecopiés seulement depuis une instance de votre ordinateur
Mods absents de ModrinthInclusSignalés, à copier à la main
FormatUn fichier, ouvert d'un double-clicUn texte à coller (Discord, message…)
Crée une instanceOuiNon : il complète une instance existante

En pratique :

  • .kpack : quand tout le monde doit avoir exactement les mêmes mods, par exemple le modpack d'un serveur moddé, où la moindre différence de version empêche de se connecter. Voir Modpacks.
  • Blueprint : pour retrouver vos mods d'optimisation, shaders et packs dans une instance d'une autre version, ou conseiller une liste de mods à un ami sans lui imposer de version.
  • Mes indispensables : un blueprint gardé par Kodus et ajouté automatiquement à chaque nouvelle instance (voir plus bas).

Copier un blueprint ​

Sur la page d'une instance, cliquez sur Blueprint, puis sur Copier le blueprint. Le texte ressemble à ceci :

[Kodus] Blueprint « Survie » (Fabric 1.21)
Mod : Sodium (sodium)
Mod : Iris Shaders (iris)
Shader : Complementary Shaders - Reimagined (complementary-reimagined)
Fichier perso : mon-mod.jar
Réglages : survie_1.21

Vous pouvez l'envoyer à un ami, ou supprimer des lignes avant de le coller. Les bibliothèques comme Fabric API n'y figurent pas : Kodus les installe automatiquement quand un mod en a besoin.

Coller un blueprint ​

  1. Ouvrez l'instance cible, cliquez sur Blueprint, puis sur Coller depuis le presse-papiers.
  2. Kodus indique, pour chaque contenu, s'il sera installé, s'il est déjà présent ou s'il n'existe pas pour cette version (par exemple un mod réservé à Fabric dans une instance NeoForge).
  3. Décochez ce que vous ne voulez pas, puis cliquez sur Installer.

Si le blueprint vient d'une instance de votre ordinateur, Kodus propose aussi de recopier les réglages de ces mods et shaders (options de Sodium, shader choisi dans Iris, réglages du shader…). Les réglages déjà présents dans l'instance cible ne sont jamais écrasés.

Les fichiers ajoutés à la main (introuvables sur Modrinth) sont signalés : copiez-les vous-même s'ils existent pour la version de l'instance.

Mes indispensables ​

Pour ne plus jamais réinstaller vos mods habituels à la main :

  1. Dans votre instance habituelle : Blueprint → Copier le blueprint → En faire mes indispensables.
  2. Dans Paramètres → onglet Jeu → Mes indispensables, activez Les ajouter à chaque nouvelle instance.

Chaque nouvelle instance, y compris celles créées par Jouer avec un mod, reçoit alors vos indispensables dans la bonne version. La fenêtre Nouvelle instance propose aussi une case pour les ajouter, ou non.
