Installer Kodus ​

Les fichiers d'installation sont disponibles sur la page des versions, dans la section Assets.

FichierUsage
Kodus-Setup-….exeWindows, recommandé (mises à jour automatiques)
Kodus-…-portable.zipWindows, si l'installeur est bloqué
Kodus-…-mac-arm64.dmgMac équipé d'une puce Apple (M1, M2, M3…)
Kodus-…-mac-x64.dmgMac équipé d'un processeur Intel

Windows ​

  1. Téléchargez Kodus-Setup-….exe, puis lancez-le.
  2. Windows affiche l'écran « Windows a protégé votre ordinateur ». Ce message apparaît parce que Kodus n'est pas signé numériquement, et non parce qu'il est dangereux. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. Suivez les étapes de l'installation. Kodus se mettra ensuite à jour automatiquement.

Si Windows bloque l'installation sans proposer « Exécuter quand même » ​

Ce blocage provient du Contrôle intelligent des applications de Windows 11. Deux solutions sont possibles.

A) Utiliser la version portable (sans mises à jour automatiques) ​

  1. Téléchargez Kodus-…-portable.zip.
  2. Faites un clic droit sur le fichier → Extraire tout, puis placez le dossier obtenu à l'emplacement de votre choix (évitez le dossier Téléchargements, pour ne pas le supprimer par erreur).
  3. Lancez Kodus.exe depuis ce dossier. Pour créer un raccourci : clic droit → Afficher d'autres options → Envoyer vers → Bureau (créer un raccourci).

B) Désactiver temporairement la protection (opération unique) ​

  1. Ouvrez les Paramètres de Windows (touches Windows + I) → Confidentialité et sécurité → Sécurité Windows.
  2. Cliquez sur Ouvrir Sécurité Windows.
  3. Accédez à Contrôle des applications et du navigateur → Paramètres du contrôle intelligent des applications.
  4. Sélectionnez Désactivé.
  5. Double-cliquez sur Kodus-Setup-….exe pour lancer l'installeur.
  6. Sur l'écran « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même, et suivez l'installation.
  7. Une fois Kodus installé, revenez au même emplacement et réactivez la protection.

macOS ​

Configuration requise : macOS 13 (Ventura) ou version ultérieure

Cela correspond approximativement aux Mac commercialisés à partir de 2017. Pour connaître votre version : menu Pomme → À propos de ce Mac.

  1. Menu Pomme → À propos de ce Mac : si la mention « Puce Apple M… » apparaît, téléchargez Kodus-…-mac-arm64.dmg ; sinon, Kodus-…-mac-x64.dmg.
  2. Ouvrez le fichier .dmg et faites glisser Kodus dans le dossier Applications.
  3. Au premier lancement, macOS refuse d'ouvrir l'application. Cliquez sur OK, puis ouvrez Réglages Système → Confidentialité et sécurité et cliquez, en bas de la page, sur Ouvrir quand même. Cette opération n'est à faire qu'une fois.
  4. Si macOS indique que Kodus est « endommagé » (ce qui n'est pas le cas), ouvrez l'application Terminal, collez la commande suivante, puis appuyez sur Entrée :
bash
xattr -dr com.apple.quarantine /Applications/Kodus.app
