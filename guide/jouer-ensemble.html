Jouer ensemble ​

Jouer ensemble permet de jouer avec vos amis par Internet, sans serveur : l'un ouvre son monde solo, les autres le rejoignent en un clic depuis Kodus. Kodus s'occupe aussi des mods : il partage votre instance avec vos amis et la garde synchronisée.

Partager une instance ​

Sur la page d'une instance, cliquez sur Partager, puis activez Partager avec mes amis.

Dès la création

Dans Nouvelle instance et sur la page Jouer avec un mod, les cases Partager avec mes amis et Héberger des parties sans serveur activent tout de suite le partage et l'hébergement de l'instance créée. Kodus retient votre choix pour la prochaine fois.

  • Vos amis voient l'instance sous votre nom, dans le panneau Amis de l'accueil.
  • Un code de partage (ex. K7P-4QX) permet aussi à un joueur Kodus qui n'est pas votre ami de l'installer. Le code ne permet pas de rejoindre vos parties.
  • Partager aussi mes réglages de mods envoie les fichiers du dossier config : vos amis choisissent ensuite de les prendre ou non.
  • Quand vous ajoutez, retirez ou mettez à jour un mod, le partage se met à jour tout seul.

Les mods marqués requis pour rejoindre sont les mods de contenu (nouveaux blocs, mobs…) : vos amis doivent les avoir pour entrer dans votre monde. Les mods visuels ou d'optimisation, comme Sodium, peuvent être différents chez chacun.

Ce qui n'est jamais partagé

Vos mondes, vos paramètres du jeu (touches, vidéo…) et les mods ajoutés à la main. Pour ces derniers, vos amis voient seulement leur nom, pour pouvoir vous les demander.

Installer l'instance d'un ami ​

  • Depuis l'accueil : cliquez sur l'étiquette 📦 sous le nom de votre ami. Depuis la page Amis : bouton Installer.
  • Avec un code : Nouvelle instance → Installer l'instance d'un ami avec un code de partage…

La fenêtre demande Où l'installer ? :

  • Nouvelle instance : une copie complète de son instance, liée (voir Synchroniser) ;
  • Dans une de vos instances de même version et même loader : Kodus n'y ajoute que ses mods requis, le reste de votre instance ne change pas.

Les contenus optionnels (mods visuels ou d'optimisation, packs de ressources, shaders) ne sont pas nécessaires pour jouer ensemble : cochez ceux que vous voulez. Ils sont tous cochés pour une nouvelle instance, aucun pour une de vos instances. Ceux que vous avez décochés ne sont jamais réinstallés par Synchroniser.

Kodus installe exactement les mêmes versions des mods que votre ami. Cochez Prendre aussi les réglages de mods si vous voulez sa configuration.

Synchroniser ​

L'instance installée reste liée à celle de votre ami. Quand il change ses mods, un point apparaît à côté de l'instance et sa page affiche Nouveautés dans l'instance de… : cliquez sur Synchroniser.

Kodus montre d'abord ce qui change (ajouté, mis à jour, retiré). Les mods que vous avez ajoutés vous-même ne sont jamais retirés, et vos mondes sont conservés.

Délier transforme la copie en instance ordinaire : elle ne propose plus de synchroniser.

Héberger une partie ​

  1. Dans la fenêtre Partager de votre instance, activez Jouer ensemble sans serveur. Kodus installe les mods e4mc (l'adresse publique) et LAN World Plug-n-Play (l'accès des joueurs Kodus). Une instance Vanilla doit passer en Fabric : rien ne change en jeu et vos mondes sont conservés.
  2. Lancez le jeu et ouvrez un monde.
  3. Échap → Ouvrir au réseau local : l'écran de LAN World Plug-n-Play s'affiche, déjà réglé par Kodus. Cliquez sur le bouton pour démarrer.

Kodus affiche Ta partie est ouverte à tes amis sur l'accueil, avec l'adresse de la partie, et prévient vos amis. La partie se ferme quand vous quittez le monde.

Online Mode

Kodus règle Online Mode sur Désactivé pour que les joueurs Kodus puissent entrer. Si l'accueil indique que Online Mode est activé, quittez le monde, rouvrez-le, puis Ouvrir au réseau local en remettant Online Mode sur Désactivé.

Visibilité

Vos amis voient votre partie même avec la visibilité « En ligne seulement ». En visibilité Invisible, ils ne la voient pas : donnez-leur l'adresse (bouton Copier).

Rejoindre un ami ​

Quand un ami ouvre une partie, Kodus vous prévient et un bouton Rejoindre apparaît sous son nom.

Kodus vous montre les mods requis et vos instances de la même version :

  • prête : cliquez sur Rejoindre, le jeu se lance directement connecté à la partie ;
  • il manque un mod ou version différente : Compléter et rejoindre ajoute les mods de contenu de votre ami à cette instance, aux mêmes versions, sans toucher au reste ;
  • Créer une copie de son instance installe son instance (liée), puis lance le jeu ;
  • Rejoindre quand même essaie avec l'instance choisie telle quelle.

Si votre ami n'a aucun mod de contenu, n'importe quelle instance de la même version convient, même Vanilla.

Si la connexion est refusée (un mod manque), Kodus propose Voir les choix pour compléter votre instance ou installer celle de votre ami.

Bon à savoir ​

  • Le relais qui fait passer la partie par Internet est fourni gratuitement par l'autrice d'e4mc, pas par Kodus : s'il est lent ou indisponible, réessayez plus tard. Aucun port n'est ouvert sur votre box et votre adresse IP n'est pas montrée.
  • Toute personne qui connaît l'adresse peut entrer tant que le monde est ouvert. Kodus ne la montre qu'à vos amis ; les commandes /ban et /whitelist permettent de filtrer.

e4all

Les premières versions de Jouer ensemble utilisaient le mod e4all. Il a été supprimé de Modrinth et signalé comme dangereux : Kodus le retire automatiquement de vos instances. Si vous l'avez installé ailleurs (autre launcher), supprimez-le et lancez une analyse antivirus.

  • Pour le Goupil SMP ou un serveur, voir Jouer en multijoueur.
